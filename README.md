## 📂 Descrição do repositório

Repositório criado para realizar o trabalho: ATVPI_01: Sistema de Gestão de Pesquisa de Satisfação

##Instruções
Desenvolver um site (organizando os arquivos e utilizando APENAS HTML)
Construir as páginas:
 Index.html => Apresentação da pesquisa / Menu de Navegação / banner de cabeçalho do site / conteúdo principal / Rodapé
- login.html =>tela com o formulário para fazer o login no sistema
- main.html => tela principal do sistema com as boas vindas. Deve apresentar todas as opções de funcionalidades previstas para o sistema , de acordo com a documentação já elaborada e em elaboração nas disciplinas de Projeto Integrador
** cada funcionalidade deve levar para uma página.
